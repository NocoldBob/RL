# 第十四篇 LunarLander 训练探测记录（开发中）

本文件记录正式多随机种子实验前的单种子探测。它不是可发布的最终实验报告。

## 已完成实现

- 8 维观测归一化；
- 二维 `tanh` 高斯 PPO 策略；
- LunarLander SAC Actor 与双 Q 网络；
- `terminated` 与 `truncated` 分离处理；
- 固定种子确定性评估；
- 最佳/最新检查点和增量历史保存；
- PPO 独立 Actor/Critic 编码器与正交初始化；
- SAC 原始奖励、`1e-3` Q 学习率和每两步一次更新。

## 探测结果（seed=42）

| 配置 | 步数 | 最佳阶段结果 | 结论 |
|---|---:|---|---|
| 共享编码器 PPO，奖励缩放 0.01 | 300k | 平均回报 -62.9 | 未学会稳定着陆 |
| 共享编码器 PPO，奖励缩放 0.01 | 1M | 最佳仍为 -62.9 | 单纯增加步数无效 |
| 独立编码器 PPO，正交初始化 | 500k | 200k 时回报 10.2、着陆率 55% | 上限提高但随后崩塌 |
| 独立编码器 PPO，原始奖励 | 100k 后停止 | 回报约 -306.6 | Critic 对尺度不稳定 |
| SAC，奖励缩放 0.01 | 150k 后停止 | 50k 时回报约 -49 | 未着陆，温度快速降低 |
| SAC，原始奖励、Q 学习率 1e-3 | 200k 后停止 | 50k 时回报约 -11.8 | 后续退化，未着陆 |

## 下一轮稳定化顺序

1. PPO 增加目标 KL 早停，并把每轮更新次数从 10 降至 5；
2. 保存策略熵、价值解释方差和裁剪比例，定位策略崩塌发生点；
3. SAC 分离 Actor/Q/温度学习率，并记录 alpha、Q 目标与 TD 误差；
4. 先用 3 个 200k 探测种子筛选配置，再运行完整多种子预算；
5. 只有平均回报越过 200 且多种子结果可复现后，才撰写第十四篇正式正文。
